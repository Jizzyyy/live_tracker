# Live Tracker

Real-time location sharing app built with Flutter.

## Tech Stack

- **Framework:** Flutter
- **State Management:** Riverpod
- **Maps:** OpenStreetMap via `flutter_map`
- **Architecture:** Feature-first

## Getting Started

```bash
flutter pub get
flutter run
```
